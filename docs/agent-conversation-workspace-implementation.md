## 2026-09-10：草稿编辑器存储边界与指定版本生成

本轮实际改动：

- `WorkflowEditor` 支持注入草稿存储、检查点、退出、历史、素材参数和执行接口。节点操作统一经过该存储入口，草稿模式关闭正式库快照与从 ComfyUI 历史直接新建库文件的路径。普通工作流路由仍使用原存储。
- 新增独立的 `ComfyMobileAgentDrafts` IndexedDB 存储及 `DraftWorkingCopy`。工作副本按 server/session/draft/打开的历史版本隔离；本地 CAS 检测多个编辑器的冲突。网络请求前持久化不可变请求，回包丢失后先重放原 requestId/sourceRevision/expectedHeadRevision，再提交期间产生的新修改。磁盘失败和远端冲突保留错误与未同步内容。
- `DraftWorkflowStorage` 只保存 canvas/bindings，不把运行时 graph、正式库 cloud 元数据和同步 outbox 混入草稿。素材绑定辅助函数同时改 canvas token 与 binding，保持绑定 ID；删除 loader 清除其绑定，普通字符串修改不能绕过已有绑定。
- 官方画布扩展新增可检测的会话执行能力：`workspaceExecution=1` 时，官方 queue 动作通知父页面；直接 API queue 被阻止。父页面校验 iframe 来源及能力，旧扩展显示四语说明，可以退出或切回手机画布。尚未在实际 ComfyUI 官方前端验证这一新增桥接行为。
- 新增 `POST /sessions/:sid/runs` 和 `WorkspaceApi.generate`。固定 draft/revision 创建 directRun Task，复用原 Run 确认、调度和恢复，不需要配置语言模型，终态不恢复模型循环。重复请求返回原 Task/Run；不同参数或聊天请求不能复用相同 requestId。
- 任务、操作计划和 Run 原子登记要求嵌套事务；AgentStore 保留外层 BEGIN IMMEDIATE，内层用 SAVEPOINT。测试覆盖内层失败被捕获后的回滚、外层失败回滚已释放子事务，以及归档草稿生成失败时不留下 Task/操作/事件。
