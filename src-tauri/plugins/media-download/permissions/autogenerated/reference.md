## Default Permission

Allows Comfy Mobile to save an authenticated media response with Android DownloadManager.

#### This default permission set includes the following:

- `allow-enqueue-download`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`media-download:allow-enqueue-download`

</td>

</td>
</tr>

<tr>
<td>

</td>
